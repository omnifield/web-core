# 🗔 Dialog

<h2 id="главное">🏠 Главное</h2>

🏷️ overlays · 🧬 component · 📐 regular · 📦 `@web-core/ui`

Модальное окно поверх страницы 🗔 — используйте, когда пользователь должен закончить или отменить
одно конкретное действие, прежде чем вернуться к остальному. Кит отдаёт наружу только МЕХАНИКУ
открытия/закрытия и фокус-ловушки, диммер и кнопку закрытия — не готовую панель с заголовком: что
внутри и как оно выглядит, решает и стилизует само содержимое, которое туда положил потребитель.

<h2 id="анатомия">🧩 Анатомия</h2>

Снаружи составляются только две части — `control` открывает, `content` держит содержимое.
`backdrop`/`closeTrigger` кладёт сама `DialogContent`, отдельно они не составляются, только
адресуются скином.

```
control
content
├─ backdrop
└─ closeTrigger
```

| часть              | значение                                                              | принимает внутри | рисуется         |
| ------------------- | ------------------------------------------------------------------------ | ------------------ | ---------------------- |
| 🔘 `control`       | открывает диалог                                                          | текст, иконку       | `DialogControl`     |
| ⬛ `backdrop`      | затемнённая подложка за диалогом — кладётся сама                          | ничего              | (кладётся `DialogContent`) |
| 🗔 `content`       | сама механика — портал, открытие/закрытие, фокус-ловушка; своего вида не несёт | что угодно      | `DialogContent`     |
| ✕ `closeTrigger`   | закрывает диалог — кладётся сама рядом с содержимым                       | ничего              | (кладётся `DialogContent`) |

<h2 id="использование">🚀 Использование</h2>

Ручная композиция — единственный путь; своей структуры содержимого кит не навязывает. 🔀

**Диалог целиком.**

```tsx
<Dialog>
  <DialogControl>Открыть</DialogControl>
  <DialogContent>
    <MyOwnPanel />
  </DialogContent>
</Dialog>
```

`DialogContent` уже несёт диммер и крестик закрытия сама — `MyOwnPanel` заботится только о
собственном виде: заголовок, кнопка отправки формы — всё это разметка и стили потребителя.

**Рендер через движок** — та же механика, но по схеме (сборка `basic`), которую рисует
`RenderTree`. Слот `content` остаётся пустым — реальную разметку кладёт `slots`.

```tsx
const tree = instanceOf("dialog", {}, "basic", {});

<RenderTree registry={registry} tree={tree} data={{}} slots={{ dialog: { render: () => <MyOwnPanel /> } }} />;
```

**Диалог-предупреждение.** `role="alertdialog"` на `Dialog` — фокус по умолчанию уходит на первый
элемент внутри содержимого, клик снаружи диалог не закрывает.

```tsx
<Dialog role="alertdialog">
  <DialogControl>Удалить аккаунт</DialogControl>
  <DialogContent>
    <ConfirmDeletePanel />
  </DialogContent>
</Dialog>
```

**Общий диалог на несколько control.** `value` у `DialogControl` различает, какой из них открыл
диалог — тот же приём, что у `drawer`/`popover`.

```tsx
<Dialog onTriggerValueChange={(details) => setActiveUserId(details.value)}>
  <For each={users}>{(user) => <DialogControl value={user.id}>Изменить {user.name}</DialogControl>}</For>
  <DialogContent>
    <EditUserPanel />
  </DialogContent>
</Dialog>
```

> [!NOTE]
> Контекст течёт сквозь `Portal` как обычно — `Portal` из `solid-js/web` сохраняет владельца,
> не заводит отдельный реактивный корень. Любой `Context.Provider`, поставленный снаружи
> `<Dialog>`, доступен внутри `MyOwnPanel` через `useContext`, проверено тестом.

<h2 id="состояния">🎛️ Состояния</h2>

|      | состояние      | метка                    | где                          | значение                                            |
| ---- | --------------- | -------------------------- | ------------------------------ | ------------------------------------------------------ |
| 🔓🔒 | open / closed   | `[data-state]`              | control, backdrop, content     | диалог открыт / закрыт                                |
| 🎯   | current         | `[data-current]`            | control                        | в диалоге с несколькими control — тот, что его открыл |
| 🖱️   | hover           | `:hover`                    | control, closeTrigger           | указатель наведён                                     |
| ⌨️   | focus-visible   | `:focus-visible`            | control, closeTrigger           | фокус пришёл с клавиатуры                             |
| 👆   | active          | `:active`                   | control, closeTrigger           | нажат указателем                                      |

<h2 id="io">🔌 IO</h2>

Собранная по схеме сборка не носит данных вовсе — содержимое приходит через `slots`, не через
`bind`/`repeat`. У кита нет `entity/io.ts` — заводить нечего.

<h2 id="сборки">🏗️ Сборки</h2>

<h3 id="сборка-basic">🧱 basic</h3>

Чистая механика, открытая по умолчанию, без единого правила своего вида для содержимого.

```
content · providerProps: defaultOpen
```

<h2 id="рецепт">🎨 Рецепт</h2>

`content` несёт ровно одно механическое правило — `isolation: isolate` (новый stacking-контекст,
чтобы z-index потребителя внутри вёл себя предсказуемо независимо от того, куда физически попал
портал в DOM) — и переключает `display: contents`/`none` по открытости. `backdrop` — полноэкранный
слой с затемнением, `closeTrigger` — круглая кнопка в правом верхнем углу. Ни падинга, ни фона, ни
рамки, ни анимации у самого содержимого — как оно выглядит, решает и стилизует потребитель.

<h2 id="доступность">♿ Доступность</h2>

Диалог следует паттерну WAI-ARIA [Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)
— фокус попадает внутрь содержимого при открытии и не выходит за его пределы, пока оно открыто, а
после закрытия возвращается туда, откуда пришёл. ⌨️

| Клавиша            | Действие                                                    |
| ------------------- | ------------------------------------------------------------ |
| `Enter` (на control) | Открывает диалог                                            |
| `Tab`               | Переносит фокус на следующий элемент внутри содержимого, не выпуская наружу |
| `Shift + Tab`       | Переносит фокус на предыдущий элемент внутри содержимого       |
| `Esc`               | Закрывает диалог и возвращает фокус control                  |
