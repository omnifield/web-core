# 🧱 Components

Готовые Solid-компоненты общего назначения — не части конкретного компонента кита, а строительный
блок, которым какой угодно компонент может собрать СВОЮ часть.

- **`own-part.tsx`** — фабрика для части анатомии, которую придумал сам кит и у которой нет
  готового коннектора от поставщика (`ownPart(name, attrs)` возвращает компонент, который просто
  ставит на `<div>` адрес, снятый с достроенной анатомии, и снимает чужой адрес с пропов). Один
  и тот же шаблон для любого компонента, которому однажды понадобится своя, непоставленная
  поставщиком часть, — не копия одной и той же функции в очередной папке компонента.
