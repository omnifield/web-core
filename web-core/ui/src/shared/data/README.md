# 🗂️ Data

Словари — общие ЗНАЧЕНИЯ (имена полей, имена частей), которые компонент подставляет целиком, а не
набирает заново каждый раз руками.

- **`fields.ts`** — общие фрагменты формы для `entity/io.ts`. Не готовая целая схема и не
  функция на каждое поле, а каталог кусков, которые вставляются через spread
  (`{ ...fields.labeled }`) в объект схемы конкретного компонента. Одно и то же поле в разных
  компонентах физически одна и та же строка кода, а не только похожая по названию.
- **`anatomy.ts`** — общие имена частей анатомии, которые придумал сам кит (не поставщик):
  повторяющаяся форма «кликабельная шапка с индикатором + открытый слот» (`controlSet`/`content`) и
  части текста документа (`document` — заголовок, абзац, список, код, таблица, цитата, ссылка).
  Подставляются через spread — в `.extendWith(...)` к анатомии поставщика либо прямо в `.parts(...)`
  там, где машины у поставщика нет вовсе, — так же, как поля из `fields.ts`, а не отдельной
  механикой на каждый словарь.
