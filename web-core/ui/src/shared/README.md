# 🧷 Shared

`web-core/ui/src/shared/` — общий код кита, живущий ВНЕ папки конкретного компонента: то, что
нужно больше чем одному компоненту, заводится здесь один раз, а не копией на каждый, у кого
похожая нужда. Первый такой случай — реэкспорт коллекции, которым раньше отдельно везли и лист
выбора, и раскрывающийся список, каждый из своего собственного входа поставщика: работало, но
задваивало один и тот же реэкспорт в двух разных модулях. `shared/` разложен по тому, ЧТО именно
общее — код-инструмент, данные-словарь или готовый компонент, — а не свалено в одну папку без
разбора.

- 🧵 [`utils/`](./utils/README.md) — функции, которые компонент зовёт
- 🗂️ [`data/`](./data/README.md) — словари-заготовки, которые компонент подставляет целиком
- 🧱 [`components/`](./components/README.md) — готовые Solid-компоненты общего назначения
