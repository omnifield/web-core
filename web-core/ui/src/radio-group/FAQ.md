# ❓ FAQ

Короткие ответы на конкретные вопросы, которые уже возникали по этому компоненту. Не общая
документация (она в [`README.md`](./README.md)) и не план (он в [`ROADMAP.yaml`](./ROADMAP.yaml))
— только факты, каждый проверен на практике.

---

### Почему `RadioGroupItemHiddenInput` экспортирован отдельно, хотя обычная композиция его не требует?

**Коротко: он нужен только при ручной композиции с `asChild`, когда `RadioGroupItem` не рисует свою разметку сам.**

По умолчанию `RadioGroupItem` кладёт `<input type="radio" hidden>` внутрь себя сам — трогать его не
нужно. Но если разметку пункта задаёт потребитель через `asChild` (свой `<label>` вместо
дефолтного), автоматическая подстановка отключается вместе со всей остальной стандартной разметкой
— скрытый ввод в этом случае приходится класть руками, и без публичного экспорта это было бы
попросту нечем сделать.

### Почему `indicator` — один узел на весь набор, а не галочка внутри каждого пункта?

**Коротко: это скользящий указатель, который сам измеряет выбранный пункт и позиционируется поверх него — та же механика, что у скользящей полосы табов.**

`indicator` — прямой сосед `item`, не его потомок: кит измеряет геометрию ВЫБРАННОГО пункта и
пишет её в четыре переменные (`--left`/`--top`/`--width`/`--height`), а рецепт центрирует
маленькую точку внутри этого измеренного прямоугольника. Один общий узел вместо галочки в каждом
пункте — тот же архитектурный выбор, который уже сделан для `segment-group`'s скользящей пилюли,
просто с другим итоговым видом.

### Почему `disabled`/`invalid` можно поставить и на весь набор, и на один пункт — это не дублирование?

**Коротко: нет, это две разные вещи — «весь набор недоступен» и «один конкретный вариант недоступен», у форм это частый сценарий.**

Групповой `disabled` (на `RadioGroup`) выключает весь набор разом — типичный случай для формы
целиком. Проп `disabled` прямо на одном `RadioGroupItem` выключает только ЭТОТ вариант, оставляя
остальные кликабельными — пригождается, когда конкретный выбор временно недоступен (например,
способ доставки, которым сейчас нельзя воспользоваться), а не весь набор целиком. Это два
независимых, одновременно работающих переключателя, не альтернативные способы одного и того же —
тот же довод, что уже применён к `segment-group`.
