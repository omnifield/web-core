# ❓ FAQ

Короткие ответы на конкретные вопросы, которые уже возникали по этому компоненту. Не общая
документация (она в [`README.md`](./README.md)) и не план (он в [`ROADMAP.yaml`](./ROADMAP.yaml))
— только факты, каждый проверен на практике.

---

### Почему клик по стрелке/точке не проверен тестом, хотя это самая базовая функция карусели?

**Коротко: настоящая страница определяется через `IntersectionObserver` после настоящей прокрутки — jsdom не выполняет ни то, ни другое.**

В браузере переход между страницами карусели — это не мгновенная смена состояния по клику, а
следствие: клик запускает прокрутку, а какая страница «текущая» решает браузер, реально сообщая,
какой слайд видно на экране. В тестовом окружении оба механизма — заглушки без единого настоящего
события, поэтому клик по стрелке или точке не меняет ничего наблюдаемого. Это ограничение среды,
не дефект компонента — подробности и честная пометка каждой такой фичи как непроверенной —
`ROADMAP.yaml`.

### Почему `progressText` в базовой сборке ничего не показывает, и как вообще получить текст вида «2 из 5»?

**Коротко: узел смонтирован, но без переданного содержимого показывать ему нечего — а способ достать готовый текст программно кит сейчас не даёт вовсе.**

`CarouselProgressText` — обычная часть с адресом, куда нужно положить готовый текст самому; сам
узел число страниц не форматирует. Программного доступа к состоянию карусели (текущая страница,
готовый текст прогресса, переход к конкретному слайду, пауза/возобновление автопрокрутки) кит
сейчас не даёт ни одним публичным способом — честно вынесено как пробел, `ROADMAP.yaml`.
