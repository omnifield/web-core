# ❓ FAQ

Короткие ответы на конкретные вопросы, которые уже возникали по этому компоненту. Не общая
документация (она в [`README.md`](./README.md)) и не план (он в [`ROADMAP.yaml`](./ROADMAP.yaml))
— только факты, каждый проверен на практике.

---

### В ките раньше было два разных `Toggle` — актуально ли это?

**Коротко: нет — второго `Toggle` в текущем коде не существует, это устаревшая заметка.**

README когда-то предупреждал не путать этот компонент со «старым» тумблером на другом движке —
проверка (2026-09-04) не нашла второго `Toggle` нигде в исходниках: единственный экспорт с этим
именем идёт из этой самой папки. Заметка описывала промежуточное состояние миграции, которое уже
закончилось, но осталась в документации. Не доверять таким предупреждениям на слово — искать
второй файл самому, если сомнение важно для задачи.

### `data-state`, `data-pressed` и `aria-pressed` — можно полагаться на любой из трёх?

**Коротко: да, все три — реальные, независимо объявленные метки одного и того же факта.**

Ни одна из трёх меток не выведена из другой — просто три способа записать «нажат» для разных
потребителей (aria — для ассистивных технологий, не для стилей). В рецепте можно опираться на
любую, какая удобнее для конкретного правила.

### Индикатор наследует состояние визуально от кнопки, или у него своё?

**Коротко: своё, независимое — просто оно всегда совпадает по факту с состоянием кнопки.**

И кнопка, и глиф внутри неё несут идентичный набор меток о нажатости одновременно, каждый сам по
себе — не так, что кнопка «главная», а глиф просто наследует её вид. Псевдоклассы указателя
(наведение, фокус, нажатие) — только на самой кнопке: глиф внутри декоративный, не отдельная
интерактивная поверхность.
