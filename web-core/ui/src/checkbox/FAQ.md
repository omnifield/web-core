# ❓ FAQ

Короткие ответы на конкретные вопросы, которые уже возникали по этому компоненту. Не общая
документация (она в [`README.md`](./README.md)) и не план (он в [`ROADMAP.yaml`](./ROADMAP.yaml))
— только факты, каждый проверен на практике.

---

### Почему у всех четырёх частей одинаковый набор состояний, а не только у самого квадрата?

**Коротко: у чекбокса нет части, которая «владеет» состоянием больше других — так и задумано.**

Отмечен, отключён, наведён и так далее — движок отдаёт один и тот же набор атрибутов для каждой
части сразу: и для всей строки целиком, и для видимого квадрата, и для указателя внутри него, и
для подписи. Это позволяет красить любую часть под любое состояние независимо — например, менять
цвет подписи при наведении, не трогая сам квадрат.

### Почему `:hover`/`:focus`/`:active` в CSS не работают на чекбоксе?

**Коротко: реальный фокус и наведение отслеживаются не на видимых узлах — движок кладёт их данными.**

Настоящий фокус лежит на скрытом `<input>`, который и обеспечивает доступность с клавиатуры, а не
на самом квадрате или подписи — обычные псевдоклассы браузера на них просто не сработают. Движок
сам следит за указателем и фокусом и выставляет результат атрибутами (`data-hover`, `data-focus`,
`data-focus-visible` и так далее) — их и нужно использовать в рецепте, не псевдоклассы.

### Почему указатель отметки (галочка) не показывается, хотя стиль вроде бы прописан?

**Коротко: он скрыт нативным атрибутом `hidden`, пока чекбокс не отмечен — стиль тут ни при чём.**

Указатель прячется не через `display: none` в базовом виде (это перебило бы отображение для
КАЖДОГО чекбокса разом, специфичностью), а через нативный атрибут `hidden`, который движок сам
ставит и снимает по состоянию. `display` в рецепте появляется только внутри состояний
«отмечен»/«отчасти» — не в базе.

### Можно ли показать разную графику для «отмечен» и «отчасти» одновременно?

**Коротко: да — два указателя рядом, движок сам покажет нужный и спрячет второй.**

Второй указатель с собственным пропом «отчасти» показывается только в состоянии «отчасти» и прячет
первый (обычную галочку) — оба живут внутри одной рамки одновременно, переключение чисто
визуальное, оба всегда в разметке.
