# DBP

## Индекс-файл папки

Два разных случая, и `index` в них разное.

**Папка-россыпуха.** Каждый файл внутри несёт свою отдельную механику, файлы друг друга не
собирают. `index` тут — просто барел, публичный API: реэкспорт того, что снаружи можно брать.
Пример — `src/entities/mapping/index.ts`: `describeVariant` и `applyMapping` — два независимых
примитива, барел просто собирает оба в одну дверь наружу.

**Папка — одна общая механика, декомпозированная на файлы.** Файлы — части одного целого, не
самостоятельные штуки. `index` тут — сам рут: компонент/функция, которая внутри собирает все части
воедино. Снаружи видно только рут, части — его внутренняя декомпозиция, не отдельный API.

Пример второго случая — `src/widgets/tree/index.ts`: реэкспортирует `Tree` из `root.tsx`, который
внутри собирает `Node`/`Leaf` в дерево. Не барел — `root.tsx` физически и есть публичный компонент,
`index.ts` только называет файл снаружи привычным именем.
