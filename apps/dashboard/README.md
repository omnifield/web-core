## 🏠 Главное

📊 Демонстрация того, чего не видно на витрине: **модуль, собранный в студии, живёт в чужом
приложении** — там, где нет ни студии, ни службы пресетов. Человек собирает модуль, выгружает его
файлом, кладёт файл сюда, дописывает строку — и модуль рисуется, одетый, с данными. Поменял модуль
в студии, заменил файл — картинка изменилась.

🚫 Это не продукт и не вторая витрина. Экран один, сети нет ни одной, бизнес-логики нет вовсе. Всё,
что приложение делает, оно делает уже существующими средствами фреймворка: понадобилась новая
механика — это заявка владельцу соответствующей зоны, а не код в этой папке.
