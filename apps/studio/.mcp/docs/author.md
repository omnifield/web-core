# Владение записями: `author`

`author` в `save_preset`/`save_content` — не просто подпись, а единственная граница доступа в
этой зоне.

## Правило

- У записи ЕСТЬ `author` — переписать её может только запрос с ТЕМ ЖЕ `author`. Другой (или
  отсутствующий) `author` — отказ, запись не тронута.
- У записи НЕТ `author` (никогда не был задан) — открыта всем, пишет кто угодно.
- Нет иерархии, нет секрета: любое имя защищено ровно одинаково, включая ваше собственное.

## Откуда берётся `author` — заголовком, не аргументом

На HTTP-транспорте личность приезжает заголовком запроса `X-User-Login` — его ставит платформа,
через которую вы работаете (она уже знает, с каким залогиненным юзером говорит), не вы сами.
Заголовок победит ЛЮБОЕ значение аргумента `author`, даже если вы его укажете — не пытайтесь
подставить своё или чужое имя аргументом, оно не сработает, пока платформа шлёт заголовок.

Аргумент `author` — резерв ТОЛЬКО для мест без заголовка вовсе (локальный запуск по stdio,
служебные скрипты вроде `push-to-prod.mjs`). Если вы работаете через платформу по HTTP — просто не
трогайте `author`-аргумент, он не нужен и не имеет эффекта.

## Просмотр — всем, защита — только на перезапись

`list_presets`/`get_preset`/`list_content`/`get_content` не фильтруют по `author` — записи любого
владельца видны всем. Это не пробел, а тот же выбор, что и защита выше: `author` охраняет ЗАПИСЬ
(перезапись/переопределение существующего), не ЧТЕНИЕ. Отдельной модели «вижу только своё» для
`content` нет и не планируется — она была бы исключением из общего правила, не более безопасным
поведением (коллизия по имени и так получает отказ `authorGuard`, а не тихую перезапись).

## Что это НЕ означает

- Это не аутентификация в полном смысле. Эта зона не проверяет, что заголовок настоящий — доверие
  к источнику лежит на платформе/сети (кто может писать этот заголовок), не на этой проверке.
- Это не секрет вроде токена. Сравнение идёт по строке из заголовка, но сама строка — не пароль,
  агент её не печатает и не может подделать (заголовки транспорта агенту не подконтрольны, только
  аргументы тула — а аргумент теперь заведомо проигрывает заголовку).
