# 3. Составной компонент — части собираешь ты

**Показываем:** компонент из нескольких частей собирается вложенностью, как обычная разметка.
**Зачем:** это второй и последний способ строить руками. Дальше в гайде будет движок — но он для
другого случая, а не «более правильный».

## 💻 Код

```tsx
import { For } from "@web-core/solid";
import {
  Accordion,
  AccordionItem,
  AccordionControl,
  AccordionControlIndicator,
  AccordionContent,
} from "@web-core/ui";

const SECTIONS = [
  { value: "what", title: "Что это", text: "Демка фреймворка и площадка для своих экспериментов." },
  { value: "how", title: "Как работает", text: "Компоненты кита, вид отдельно, данные отдельно." },
  { value: "why", title: "Зачем", text: "Чтобы собрать своё, не собирая каждый примитив заново." },
];

export function CompositeComponent() {
  return (
    <Accordion defaultValue={["what"]}>
      <For each={SECTIONS}>
        {(section) => (
          <AccordionItem value={section.value}>
            <AccordionControl>
              {section.title}
              <AccordionControlIndicator />
            </AccordionControl>
            <AccordionContent>{section.text}</AccordionContent>
          </AccordionItem>
        )}
      </For>
    </Accordion>
  );
}
```

## 🧠 Что запомнить

- **Вложенность повторяет владение.** Индикатор лежит внутри заголовка, потому что принадлежит
  ему, а не стоит рядом. Так же устроен любой составной компонент кита.
- **Наружу кит отдаёт только то, что правда собирают по-разному.** Технические узлы (фокус,
  доступность, провайдер состояния) компонент кладёт в себя сам — искать их в импортах не нужно,
  их там нет намеренно.
- **Состояние раздела держит сам компонент.** `defaultValue` задаёт начальное; если нужно управлять
  снаружи — это обычный контролируемый проп, как в любом Solid-компоненте.
- **Список рисуется `<For>`, а не `.map()`.** Это не вкус: `map` пересоздаёт узлы целиком на каждое
  изменение, `For` держит их по ссылке на элемент. Канон включён в пресете линтера, так что `.map()`
  в разметке просто не пройдёт проверку.
