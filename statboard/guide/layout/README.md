# 7. Расставить — без единой строки своего CSS

**Показываем:** раскладку экрана токенами шкалы вместо собственных пикселей.
**Зачем:** пиксели, набитые на глаз, расползаются от экрана к экрану. Шкала одна на всё
приложение, и её значения приезжают вместе с нарядом.

## 💻 Код

```tsx
import { layoutGroup, layoutSelf, railVar } from "@web-core/skin";

export function Layout() {
  return (
    <div style={{ display: "flex", ...layoutGroup({ direction: "column", gap: "space-4" }) }}>
      <header>Заголовок</header>

      <div style={{ display: "flex", ...layoutGroup({ direction: "row", gap: "space-2" }) }}>
        <aside style={{ "inline-size": railVar("rail-md") }}>Рельса</aside>
        <main style={layoutSelf({ grow: true })}>Основное — занимает остаток</main>
      </div>
    </div>
  );
}
```

## 🧠 Что запомнить

- **Две разные функции, и их легко перепутать.** `layoutGroup` — как элемент расставляет СВОИХ
  детей. `layoutSelf` — место САМОГО элемента в чужом потоке. Имена полей похожи (`align`,
  `justify`), но ложатся в разные CSS-свойства, поэтому они и разведены.
- **`display` ставишь сам.** Обе функции отдают только свойства раскладки — flex/grid включается
  обычным `display`, как в любом CSS.
- **Токен — имя ступени, не число.** `space-4`, `rail-md` — значения им даёт надетый наряд. Имя не
  из шкалы уронит вызов сразу, с перечнем допустимых, — а не превратится в тихо игнорируемый CSS.
- **Шкал ширины несколько, и они не взаимозаменяемы:** рельса (`rail`), самостоятельная карточка
  (`card`), крупная область (`layout`). Это три разных факта про ширину.

## 🚫 Чего тут нет

- Отступов на самих компонентах кита: внешний отступ ставит тот, кто расставляет, а не компонент.
  Именно поэтому раскладка — отдельный кейс.
