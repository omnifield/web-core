# 5. Светлая и тёмная — одна кнопка

**Показываем:** переключение половины наряда.
**Зачем:** это первое, что просят у любой демки, и делается это одной строкой — а не вторым
набором стилей.

## 💻 Код

```tsx
import { useSkin } from "@web-core/skin/solid";
import { Button } from "@web-core/ui";

export function ModeSwitch() {
  const skin = useSkin();
  const mode = () => skin.worn()?.mode ?? "light";

  return (
    <Button onClick={() => skin.setMode(mode() === "dark" ? "light" : "dark")}>
      Половина: {mode() === "dark" ? "тёмная" : "светлая"}
    </Button>
  );
}
```

⚠️ **Компонент с `useSkin()` живёт ПОД `<Skin>`, а не рядом.** Позовёшь хук в том же компоненте,
который рисует провайдер, — получишь отказ «вне `<SkinProvider>`»: контекст видят потомки, а не
их создатель.

## 🧠 Что запомнить

- **Обе половины уже в браузере.** Они приехали одним текстом CSS, когда наряд надевался, —
  переключение не ходит за новым видом никуда.
- **Половина — флаг на корне страницы**, а не отдельная тема. Поэтому смена мгновенная и ничего
  не перерисовывается заново.
- **Выбор запоминается сам.** Механика кладёт его в хранилище браузера; своего кода для этого
  писать не нужно.
- **`worn()` — это `{ name, mode }`**: во что одеты и в какой половине. `null` значит «наряд ещё не
  надет», а не «сломалось».

## 🚫 Чего тут нет

- Выбора между несколькими нарядами: в демке наряд один. Если нарядов несколько, их имена отдаёт
  тот же источник (`names()`), и надеваются они по имени.
