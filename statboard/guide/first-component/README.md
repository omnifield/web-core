# 2. Первый компонент — обычный импорт, обычный JSX

**Показываем:** компонент кита — это просто Solid-компонент. Импортировал, поставил, работает.
**Зачем:** снять главный страх. Никакого особого способа «правильно вызвать» компонент нет.

## 💻 Код

```tsx
import { createSignal } from "@web-core/solid";
import { Button } from "@web-core/ui";

export function FirstComponent() {
  const [count, setCount] = createSignal(0);

  return (
    <>
      <Button onClick={() => setCount(count() + 1)}>Нажми меня</Button>
      <p>Нажатий: {count()}</p>
    </>
  );
}
```

Всё. Ни провайдера, ни регистрации, ни конфигурации.

## 🧠 Что запомнить

- **Кнопка выглядит голой — и это не поломка.** Кит не несёт ни одного стиля по умолчанию: вид
  приезжает отдельно, скином (ступень 3). До этого момента браузер рисует её так, как рисует любой
  `<button>` без CSS.
- **Пропсы — свои, кита.** Компонент не требует знать, на чём он собран внутри: работают обычные
  `onClick`, `disabled` и остальное, чего ждёшь от кнопки.
- **Вход в кит один** — `@web-core/ui`. Неиспользованные компоненты в твою сборку не попадут,
  сборщик их выбросит.

## 🚫 Чего тут нет

- Компонента из нескольких частей — это кейс 3.
- Вида и вариантов — ступень 3.
